# 回合系统说明（第2版）

## 🎮 游戏结构

游戏分为 **51个回合**，每回合3关，共 **153关**。

### 回合公式

- **第N回合**：第 `(N-1)*3+1` 关 ~ 第 `N*3` 关
- **Boss战**：每回合的第3关（第3、6、9...153关）
- **失败重试**：回到当前回合的第1关

### 示例

| 回合 | 关卡范围 | Boss关 |
|------|---------|-------|
| 第1回合 | 第1-3关 | 第3关 |
| 第2回合 | 第4-6关 | 第6关 |
| 第3回合 | 第7-9关 | 第9关 |
| ... | ... | ... |
| 第51回合 | 第151-153关 | 第153关 |

## 📋 失败与重试逻辑

| 场景 | 重试起点 | 说明 |
|------|---------|------|
| 回合N中任意位置死亡 | 回合N的第1关 | 回到该回合起点 |
| 通关全部153关 | 第1关 | 从头开始新一轮 |

## 🔧 代码实现

### 关键函数

```javascript
function getRoundStartRoom(room){
  return Math.floor(room/3)*3;
}
```

**作用**：根据当前关卡号(0-based)，计算该回合的起始关卡。每3关一回合。

### Boss循环

3种Boss外观（boss01/boss02/boss03）每3回合循环一次：

```javascript
function getBossResourceName(room){
  return ROUND_BOSS_TYPES[Math.floor(room/3)%3];
}
```

Boss属性按公式缩放：
- `cycle = Math.floor(room / 3)` — 第几个3关组
- `scale = 1 + cycle * 0.2` — 每轮Boss攻防+20%
- CD缩短、弹幕数量增加

## 🎯 游戏流程

```
第1回合(第1-3关, Boss第3关) → 
第2回合(第4-6关, Boss第6关) → 
... → 
第51回合(第151-153关, Boss第153关) →
恭喜通关！返回第1关
```

失败时回到当前回合的第1关。

## 📝 配置说明

武器、敌人、关卡配置在 `game-config.json` 中，由 `generate-config.js` 生成。

- 武器每关自动升级（3种武器各153级）
- 敌人基础属性不变，通过每个关房的 `diff` 系数缩放
- 房间难度系数 `diff` 从 1.0 线性增长至 6.32
- Boss 属性每轮缩放（攻防血逐轮增加）
