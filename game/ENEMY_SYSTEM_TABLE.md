## 2. 属性字段说明

| 字段 | 全称 | 单位 | 说明 |
|------|------|------|------|
| **hp** | Health Points | 点 | 基础生命值 |
| **spd** | Speed | 像素/帧 | 移动速度（= 玩家移动速度系数） |
| **dmg** | Damage | 点 | 单次攻击伤害 |
| **sz** | Size | 瓷砖倍数 | 体型 → 碰撞半径为 `TILE × sz`（TILE=48，实际碰撞约26~41px） |
| **ar** | Attack Range | 瓷砖倍数 | 攻击触发距离 = `TILE × ar` |
| **ac** | Attack Cooldown | 帧数 | 攻击冷却（越低越频繁） |
| **sc** | Score | 分 | 击杀积分奖励 |
| **rng** | Ranged | 布尔 | `true`=远程（发射弹丸），`false`=近战（直接伤害） |
| **col** | Color | HEX | 降级绘制颜色（精灵未加载时的备选色） |

## 6. 怪物刷新系统流程图

```
每帧 tick() 60fps
    ↓
spawnTimer 每帧+1
    ↓
spawnTimer ≥ spawnInt ? ──否──→ 跳过
    ↓ 是
spawnTimer = 0
    ↓
随机选择数量 cnt ∈ [spawnMin, spawnMax]
    ↓
循环 cnt 次:
    ├─ 从 enemyTypes[] 中随机选1种
    ├─ 读取该类型基础属性 ED[type]
    ├─ 读取本关难度系数 ROOM_CFG[room].diff
    ├─ HP = Math.round(基础HP × diff)
    ├─ DMG = Math.round(基础DMG × diff)
    ├─ 其余属性(spd,sz,ar,ac,sc) 使用基础值不动
    ├─ curA = ac + random(0~40)
    ├─ 在玩家周围80~260像素圆弧随机位置生成
    └─ 推入 G.enemies[]
```

## 7. 补充说明

1. **仅HP和DMG受难度缩放**：spd（速度）、sz（体型）、ar（攻击范围）、ac（攻击间隔）、sc（积分）在所有关卡均使用基础值不变

2. **hero290xxx = 换色/换皮变体**：10个hero290xxx怪物分别对照slime/skel/ghost/elite的基础属性完全一致，仅颜色不同用于视觉区分

3. **elite在第4关被写了两次**：`enemyTypes`数组是 `["skel","ghost","elite","elite"]`，意味着elite刷出概率是其他类型的2倍

4. **Boss生成条件**：① 关卡配置bossScore>0 ② 玩家当前积分达到bossScore ③ G.boss尚未存在。三者同时满足才生成

5. **刷怪上限**：全局固定25只（代码 `G.enemies.length<25`），超过后暂停所有生成

6. **Boss不参与难度缩放**：BOSS_CONFIG中的hp/dmg是固定值，不受 `ROOM_CFG[room].diff` 影响

7. **远程怪物特殊行为**：ghost系（含h092/h093/h095）rng=true，攻击时会发射弹丸(`addProj()`)而非直接碰撞伤害，ar=7.0表示可以在7格TILE距离外开火
