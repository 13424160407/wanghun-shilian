# 游戏流程修复说明

## ✅ 已修复的问题

### 1. start-btn 按钮逻辑修复
**问题**：`start-btn` 按钮总是调用 `startGame(0)`，导致通关后也返回第1关

**解决**：修改start-btn的事件处理，现在会根据游戏状态（phase）判断：
- `G.phase==='menu'` → 调用 `startGame(0)` 从第1关开始
- `G.phase==='dead'` → 调用 `startGame(roundStart)` 回到该回合起点
- `G.phase==='win'` → 调用 `goRoom(nextRoom)` 进入下一关（或返回第1关如果是第10关）

### 2. 添加调试日志
在关键函数添加了 `console.log`，方便追踪问题：
- `dmgBoss()`: 显示Boss战胜利信息和下一关信息
- 按键事件处理：显示当前phase和room

## 🧪 测试步骤

### 方法1：通过浏览器控制台查看日志

1. 打开浏览器（Chrome/Firefox）
2. 进入 `http://localhost:5500/game.html`
3. **按F12打开开发者工具**，切换到"控制台"标签
4. 开始游戏，推进到第3关
5. 击败第3关Boss
6. 观察控制台输出，应该看到：
   ```
   Boss战胜利！当前room: 2
   进入下一关: 3 名称: 第4关
   按键事件，当前phase: win 当前room: 2
   成功，当前room: 2 下一个room应该是: 3
   进入下一关，调用goRoom 3
   ```

### 方法2：观察游戏界面

1. 击败第3关Boss后，应该看到提示：**"恭喜通关! 即将进入第4关..."**
2. 按任意键或点击屏幕后，应该进入**第4关**（而不是第1关）
3. 检查左上角的关卡显示，应该显示"第4关"

## 💡 如果还是不对

### 1. 清除浏览器缓存
- **Chrome**: Ctrl+Shift+Delete → 清除缓存
- **Firefox**: Ctrl+Shift+Delete → 清除所有历史记录
- **Safari**: 开发菜单 → 清空所有网站数据

### 2. 强制刷新
- **Windows**: Ctrl+F5
- **Mac**: Cmd+Shift+R

### 3. 查看控制台错误
- 打开开发者工具（F12）
- 查看"控制台"标签是否有红色错误信息
- 截图错误信息，反馈给我

### 4. 检查 game-config.json 是否已加载
在控制台执行：
```javascript
console.log(GAME_CONFIG);
```
应该看到完整的配置对象
