二、完整部署流程（6步）

1购买域名

  • 到 阿里云、腾讯云 或 Namesilo 搜索并购买域名
  • 建议选 .com 或 .cn 后缀
  • 比如：wanghunshilian.com
  • 购买后记得完成实名认证（身份证拍照即可）

2购买云服务器

  • 推荐 阿里云 ECS 轻量应用服务器（新人优惠便宜）
  • 配置建议：1核2G 即可（官网是纯静态页面，资源消耗极小）
  • 操作系统选 Ubuntu 22.04 或 CentOS 7.9
  • 记下服务器的公网 IP 地址
  • 安全组开放 80端口（HTTP）和 443端口（HTTPS）

3ICP 备案（国内服务器必须）

  • 在云服务商控制台找到「备案」入口
  • 准备材料：身份证、域名证书、服务器实例
  • 填写网站信息：网站名「亡魂试炼」、类型「游戏娱乐」
  • 提交后管局审核，通常 7-20 个工作日
  • 审核通过后会获得一个备案号（填到网页底部）
⚠️ 注意：如果不想等备案，可以买香港/海外服务器， 不需要备案即可通过域名访问，但国内访问速度会稍慢。

4域名解析（DNS 配置）

备案通过后，在域名管理面板添加 DNS 解析记录：

记录类型：A 主机记录：@ 记录值：你的服务器公网IP（如 47.100.xx.xx） TTL：600 记录类型：A 主机记录：www 记录值：你的服务器公网IP TTL：600

配置后等待 5-10 分钟生效，用 ping 你的域名 测试是否解析成功。

5服务器上安装 Nginx 并上传文件

SSH 连接到服务器后执行：

# 安装 Nginx sudo apt update && sudo apt install nginx -y # 创建网站目录 sudo mkdir -p /var/www/wanghunshilian # 上传文件（在本地电脑执行） scp index.html Epic_fantasy_game_official_web_*.png root@你的IP:/var/www/wanghunshilian/ # 或者用 FTP 工具（如 FileZilla）上传更方便

6配置 Nginx 并启动

创建 Nginx 配置文件：

sudo nano /etc/nginx/conf.d/wanghunshilian.conf

写入以下配置：

server { listen 80; server_name wanghunshilian.com www.wanghunshilian.com; root /var/www/wanghunshilian; index index.html; location / { try_files $uri $uri/ =404; } # 游戏H5页面路由（如果游戏也在同一服务器） location /game/ { alias /var/www/wanghunshilian/game/; try_files $uri $uri/ /game/index.html; } }

启动 Nginx：

sudo nginx -t # 检查配置语法 sudo systemctl restart nginx # 重启生效 sudo systemctl enable nginx # 设置开机自启

此时访问 http://你的域名 就能看到官网了！🎉

三、配置 HTTPS（强烈建议）

没有 HTTPS，浏览器会提示「不安全」，影响用户信任。配置方法：

# 安装 Certbot（Let's Encrypt 免费证书） sudo apt install certbot python3-certbot-nginx -y # 自动配置 HTTPS sudo certbot --nginx -d wanghunshilian.com -d www.wanghunshilian.com # 按提示操作即可，证书自动续期

完成后访问 https://你的域名 就会显示安全锁标 🔒

四、把 H5 游戏接入官网

你的官网已经有「立即开始游戏」按钮，只需要把按钮链接指向游戏地址即可：

# 在 index.html 中修改按钮链接 <a href="/game/index.html" class="btn-download"> 立即开始游戏 </a> # 如果游戏部署在其他服务器，用完整地址 <a href="https://play.wanghunshilian.com" class="btn-download"> 立即开始游戏 </a>

把你 H5 游戏的打包文件（通常是 index.html + build/ 或 assets/ 目录）上传到服务器的 /var/www/wanghunshilian/game/ 目录即可。

五、上线前检查清单

  • 域名已购买并完成实名认证
  • 服务器已购买，安全组开放 80/443 端口
  • ICP 备案已通过（国内服务器）或使用海外服务器
  • DNS 解析已配置，ping 域名能通
  • 网站文件已上传到服务器
  • Nginx 已配置并启动
  • HTTPS 证书已配置
  • 底部备案号已填写真实备案号
  • 「立即开始游戏」按钮链接指向游戏地址
  • 手机端访问体验正常（响应式布局已做好）
